## 什么是 La Clave？

当习惯在笔记里记录账号密码的人，发现连锤子便签被卖后都加了 AI，不免得对个人密码安全产生一些担忧。

**La Clave** 诞生于一个纯粹的想法：做一个**绝对离线、搜索便捷、安全加密**的个人密码管理器。

**没有云端同步，没有后台偷跑请求。你的数据，永远只有你能看见。**

## 核心功能与安全理念

### 🛡️ 1. 本地存储，硬件加密
* **0 联网权限**：系统清单中彻底移除了 `android.permission.INTERNET`，连矢量图标（Material Icons v145）和字体都全量本地离线打包，代码底层完全不具备任何联网能力。
* **硬件级信封加密**：账号密码采用工业级 **AES-256-GCM** 加密存储在本地沙盒中，密钥由底层硬件安全模块（Android Keystore / StrongBox）严密保护。
* **抗暴力破解**：访问 PIN 码采用 600,000 轮 PBKDF2-HMAC-SHA256 离散加盐哈希运算，配合恒定时间比对，杜绝离线彩虹表破解与时序侧信道风险。
* **离线加密备份**：支持将密码本全量加密导出为离线备份文件，更换手机时可无缝还原，并向下兼容历史版本备份。

### 👁️ 2. 各种防窥探措施
* **智能生命周期防护**：常规场景 40 秒无操作自动锁定（新建密码时自动延长至 60 秒），锁屏后 10 秒无操作自动退出 App；应用退到后台超过 8 秒即刻重新锁定，严防离开手机时信息泄露。
* **可选开屏乱序 PIN 键盘**：解锁 App 时，PIN 码键盘按键位置可完全随机重排，防止旁人偷窥手指点击轨迹。默认开启。
* **密码截屏权限防护（FLAG_SECURE）**：只要屏幕上有任何一个密码的小眼睛被点亮，App 会自动禁止截屏、录屏与多任务窥屏。默认开启。
* **敏感剪贴板自动清除**：复制密码时自动打上 Android 13+ 系统级敏感标记（防止输入法窃取），并在 60 秒后原生延时物理清空，用完即焚。
* **可选密码复制权限**：在搜索结果和卡片中，支持明文状态下一键快速复制，亦可在设置中随时按需关闭。

### 🚀 3. 便捷录入&导入
* **从剪贴板智能转换**：支持直接复制段落文本（段落顺序为标题/账号/密码/附加信息），点击「从剪贴板智能转换」，内置正则引擎自动解析字段，一键批量入库。
* **智能本地备份定位**：点击「解密恢复密码本」时，优先在专属目录中自动搜寻并呈现最新的一份备份；若需恢复其他位置的备份，亦可调出系统文件选择器手动选取。

### 🎨 4. 不仅安全，还很优雅
* **丝滑物理动效与质感**：物理弹性抽屉、自适应系统深浅色切换、全局高质感卡片与沉浸式状态栏。
* **分类色彩标签**：为每一个分组和仓库卡片自动分配活力色彩标签，告别传统密码管理器单调沉闷的表格质感。
* **抽屉式新增与编辑**：编辑与详情抽屉支持丝滑上划调出、下划回弹收起，跟手自然。
* **独立外观字号调节**：在设置中提供「缩小 / 标准 / 放大」三段式动态字号调节，兼顾不同视力需求与屏幕尺寸。
* **无缝生物识别**：支持系统指纹/面容快速验证开屏，安全与速度兼得。

## 权限透明说明

以下是 La Clave 在 Android 系统配置文件中声明的全部权限及用途澄清：

| 权限名称 | 声明状态 | 实际用途与技术澄清 |
| :--- | :---: | :--- |
| **网络访问权限** (`INTERNET`) | **❌ 物理移除** | **彻底未声明**。从操作系统底层切断任何外网通道，即使被恶意代码注入也绝无发起任何网络请求的能力。 |
| **生物识别权限** (`USE_BIOMETRIC`) | **已声明** | 用于调用系统级指纹或面容识别传感器，实现开屏极速解锁。生物识别数据完全由系统硬件保留，应用无权接触。 |
| **存储读取权限** (`READ_EXTERNAL_STORAGE`) | **已声明** | 用于在用户主动点击「解密恢复密码本」时，从本地文件中选取已导出的加密备份文件。 |
| **存储写入权限** (`WRITE_EXTERNAL_STORAGE`) | **条件声明** (maxSdkVersion 32) | 仅在 Android 12 及以下系统上用于将导出的加密备份文件写入 Documents/LaClave 目录；Android 13 及以上系统已全面由系统分区存储接管，该权限自动失效且不被请求。 |
| **系统云备份** (`allowBackup="false"`) | **❌ 强制关闭** | 在应用配置中硬性禁用 Android 系统云端备份与 adb 备份，防止系统在后台静默将本地沙盒数据同步到第三方云端。 |

## 技术栈

* **前端核心**: React 19 + TypeScript + Vite
* **容器与原生桥接**: Ionic Capacitor v8 + Android SDK 36 (Kotlin / Java)
* **密码学与本地沙盒**:
  * 数据加密：WebCrypto 工业级 **AES-256-GCM**
  * 密钥保护层：Android 原生硬件密钥库 **Android Keystore / StrongBox**
  * PIN 密钥加固：600,000 轮 **PBKDF2-HMAC-SHA256** 与恒定时间比对
  * 历史版本兼容：内置 CryptoJS 只读兼容解析层，老用户旧版备份平滑升级
* **本地化与静态资源**: 本地矢量图标字体（Material Icons v145）与西文字体全量离线集成

## 常见问题解答 (FAQ)

### Q1: 如果我忘记了主访问 PIN 码，还能找回或恢复数据吗？
> **没有云端重置通道，但可以通过离线备份重装恢复。**  
> 因为 La Clave 采用零知识离线加密架构，本地没有后门，也没有云端服务器能远程帮你修改或重置 PIN 码。  
> **但是，只要你之前导出过加密备份文件（`.laclave`）**：你可以直接**卸载并重装 App（或清除 App 全部数据）**，重新设定一个新的主 PIN 码进入应用，然后点击「解密恢复密码本」，选择你的备份文件并输入导出时设置的备份密码，即可将所有账号密码完整恢复！  
> *因此，强烈建议在添加重要账号后，及时导出离线加密备份。*

### Q2: 更换新手机时，我该如何迁移密码数据？
> 过程非常简单：
> 1. 在旧手机的 La Clave 设置中点击「加密导出密码本」，将生成的加密备份文件保存；
> 2. 通过蓝牙、电脑数据线或面对面快传，将该文件发送到新手机；
> 3. 在新手机安装 La Clave 并设置主密码后，点击「解密恢复密码本」，选中该文件输入当时导出的备份密码即可全量恢复。

### Q3: 为什么不提供 WebDAV、OneDrive 或云端自动同步？
> “绝对离线”是 La Clave 立项的核心安全基石。任何连入公网的自动同步通道，不仅破坏了系统底层的“零网络权限”物理安全承诺，还会将攻击面暴露给不可控的第三方网络环境与 API 漏洞。若有跨设备需求，采用主动导出离线加密备份的方式，在安全可信的局域网或离线介质中转移，是最保险、最让人安心的做法。
